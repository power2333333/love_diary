# 用户需求文档

## 项目名称
情侣日记本

## 目标用户
一对情侣（2 人），仅限双方使用

## 已实现功能

### 1. 私人访问
- [x] 各自注册账号（邮箱 + 密码）
- [x] 各自登录，互不干扰
- [x] 未登录用户无法看到任何内容
- [x] 注册入口已关闭，仅现有账号可登录

### 2. 双人日记
- [x] 双方都可以写日记，无次数限制
- [x] 日记互相可见
- [x] 自定义昵称和代表色区分
- [x] 日记编辑（保留原始发布时间）

### 3. 首页
- [x] 纵向时间轴，日期倒序
- [x] 中文日期格式（如"2026年5月19日 星期一"）
- [x] 右上角写日记和设置入口
- [x] 纪念日倒计时（显示在一起天数）
- [x] 月历视图（左上角浮动，有日记的日期高亮）
- [x] 那年今日（左下角浮动，显示去年同一天的日记）

### 4. 日期详情页
- [x] 展示当天双方日记
- [x] 昵称和代表色区分
- [x] 发布时间（"记于X年X月X日 XX时XX分"）
- [x] 单篇日记全屏展开

### 5. 设置页面
- [x] 修改昵称
- [x] 修改代表色（预设 6 色 + 自定义）
- [x] 实时预览效果
- [x] 退出登录

### 6. 界面风格
- [x] 米黄色暖色调
- [x] 和纸纤维 + 菱格底纹 + 渐变层次 + 角落光晕
- [x] 毛玻璃导航栏
- [x] 纸张质感卡片
- [x] 页面淡入过渡、按钮回弹、丝滑动效

## 非功能需求
- [x] 数据云端存储（Supabase，Tokyo 区域）
- [x] 部署费用为 0（GitHub Pages）
- [x] 操作简单直观
