# 设计规范

## 色彩系统

### 主色调：米黄色（Beige）

| 色阶 | 色值 | 用途 |
|------|------|------|
| beige-50 | #fefdfb | 卡片背景 |
| beige-100 | #fdf9f1 | 页面主背景 |
| beige-200 | #faf0dd | 时间轴线条 |
| beige-300 | #f5e4c4 | 悬停效果 |
| beige-400 | #eed4a8 | 边框 |
| beige-500 | #e5c48c | 次要元素 |
| beige-600 | #d4a96a | 次重要文字 |
| beige-700 | #b8894a | 正文文字 |
| beige-800 | #9a6e3a | 标题 |
| beige-900 | #7d5a31 | 最重要文字 |

### 男女方默认代表色

| 性别 | 色值 | 色名 |
|------|------|------|
| 女性 | #FFE4E1（mistyrose） | 淡粉 |
| 男性 | #D6EAF8（淡蓝） | 淡蓝 |

## 字体

| 用途 | 字体 |
|------|------|
| 正文 | Noto Serif SC / STSong / serif（宋体类） |
| UI 组件 | system-ui（系统默认） |

## 页面布局

### 首页
- 全屏米黄色背景
- 居中纵向时间轴（max-width: 640px）
- 右上角固定按钮区（写日记、设置）
- 时间轴节点用圆点表示，日期显示在上方

### 日期详情页
- 日期大标题
- 左右或上下排列的日记卡片
- 每张卡片用作者的代表色作为背景色
- 卡片显示：作者昵称、内容、创建时间

### 写日记页
- 日期选择器（默认当天）
- 大文本输入框
- 提交按钮

### 设置页
- 表单式布局
- 昵称输入框
- 颜色选择器（预设色块）
- 保存按钮

## 响应式断点

| 断点 | 目标设备 |
|------|------|
| < 640px | 手机 |
| 640px - 1024px | 平板 |
| > 1024px | 电脑 |

手机端时间轴占满宽度，卡片上下堆叠。
