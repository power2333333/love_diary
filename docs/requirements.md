# 用户需求文档

## 项目名称
情侣日记本

## 目标用户
一对情侣（2 人），仅限双方使用

## 核心需求

### 1. 私人访问
- 各自注册账号（邮箱 + 密码）
- 各自登录，互不干扰
- 未登录用户无法看到任何内容

### 2. 双人日记
- 双方都可以写日记
- 同一日内可以写多篇，没有次数限制
- 双方的日记互相可见
- 用昵称和背景颜色区分男女方

### 3. 时间轴首页
- 首页以纵向时间轴展示所有有日记的日期
- 日期按时间倒序排列（最新的在上面）
- 右上角有"写日记"入口
- 右上角有"设置"入口

### 4. 日期详情页
- 点击时间轴上的某个日期，进入该日详情
- 展示当天双方写的所有日记
- 每篇日记用作者的昵称和代表色标注
- 显示日记的创建时间
- 如对方当天尚未写日记，显示空状态提示

### 5. 设置页面
- 可随时修改昵称
- 可随时修改代表色（从预设颜色中选择）

### 6. 整体风格
- 米黄色暖色调为主
- 适配电脑和手机屏幕

## 非功能需求
- 数据云端存储，更换设备不丢失
- 部署费用为 0
- 操作简单直观
